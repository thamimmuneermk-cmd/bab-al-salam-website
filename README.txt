BEFORE PUBLISHING
1. Confirm the business WhatsApp number. The starter currently uses +974 6650 8479.
2. Replace sample customer reviews with real reviews you have permission to publish.
3. Add your real photos and videos; replace sample gallery images.
4. Confirm current package prices, dates, hotel details, visa inclusions and terms before publishing.
5. Online payments are not activated yet. Choose a supported payment provider in Qatar, complete its merchant setup, and insert its official hosted checkout/payment link. Never collect card details directly in this static website.
6. The enquiry form sends the entered details to WhatsApp; it does not store bookings or confirm reservations.

FREE HOSTING START
- A common option is GitHub Pages for static websites. Create/sign in to GitHub, create a repository, upload index.html, then enable Pages in the repository settings.
- Add your existing domain under the Pages custom-domain setting and follow the exact DNS records GitHub shows. Domain connection may depend on your registrar/DNS settings.
- Use HTTPS once DNS verification is complete.
- If you prefer, Netlify also has a free static hosting tier; check its current plan and custom-domain rules before choosing.

IMPORTANT
This is a static starter website, not a full booking database. It does not process payments. Booking enquiries are sent to WhatsApp, and payment should be completed only through an official payment provider.
